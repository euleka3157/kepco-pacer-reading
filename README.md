# 계측 페이서 리딩

한국전력기술 계측 직렬 필기 대비 비공식 학습 자료입니다. 정적 웹사이트(HTML·PDF)라서 서버 없이 GitHub Pages, Netlify 같은 정적 호스팅에 그대로 올리면 됩니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 페이서 리딩 앱. 노란 형광이 어절 단위로 이동하며 읽기를 이끕니다. 회로·제어·전자기 전체 범위 확장 및 07 전력공학 포함 |
| `pdfs.html` | PDF 받기 페이지 |
| `questions.html` | 계측 단원별 연습 4,950문항 + 전기 기출·복원 3,876문항 문제은행 |
| `data/question-bank/` | 단원별 문제·선택지·정답·해설 데이터 |
| `pdf/00_5day_plan.pdf` | 5일 학습 플랜(타임라인·하루 체크리스트·기출 대응표) |
| `pdf/01~07_*.pdf` | 과목별 필기형 PDF(갤럭시탭 16:10 가로, 오른쪽 필기 패드) |
| `pen-notes.js`, `pen-notes.css` | 리더와 문제은행의 S펜 전용 필기 노트 |
| `404.html` | 잘못된 주소를 첫 화면으로 돌려보냄 |
| `.nojekyll` | GitHub Pages가 파일을 가공하지 않도록 하는 빈 파일 |

## 수록 범위

- 학습 01~07권: 236개 단원, 공식 카드 657개. 안내를 포함한 PDF 8권, 총 1171쪽.
- 제공된 회로·제어·전자기·전력 노트의 모든 학습 페이지를 확인하여 개념·공식·비교 조건을 새 설명과 예제로 반영했습니다. 원문 페이지의 복제본은 아닙니다.
- 5일 플랜과 A/B 우선순위는 학습 순서입니다. 확장 단원을 읽을 때는 ‘핵심만’을 끄고 전체 본문을 보세요. 문제은행의 기존 8,826문항은 그대로 유지합니다.

- 독자 제작 도식 272개(원본 밖 보충 38개 포함)를 관련 단원 429곳에 연결했습니다. 회로·결선·파형·벡터·기기 동작·발전 과정의 그림은 웹과 PDF에 함께 들어 있습니다. 웹 그림을 누르면 원본 크기로 열립니다.

## 페이서 리딩 사용법

- ▶ 재생, 단어를 누르면 그 위치부터, ◀ ▶ 버튼은 문장 단위 이동
- 속도 60~600 어절/분, 묶음 1~3어절, 글자 크기, 핵심만(통암기·공식·표·함정), 읽은 곳 흐리게, 문장 끝 쉼, 전체화면
- 갤럭시탭 가로(목차 고정)·세로(목차 서랍) 모두 지원, 다크모드 자동
- 읽던 위치와 설정은 각자 브라우저에만 저장됩니다(서버 전송 없음)

## 음성 읽기(한국어 TTS)

- 하단 **음성 읽기**를 켜고 ▶를 누르면 기기에 설치된 한국어 음성이 문장 단위로 읽고, 노란 형광이 읽는 단어를 따라갑니다.
- **배속** 0.5~3배, **목소리** 선택, **수식 읽기**(수식을 "R 분의 V 제곱"처럼 한국어로 읽음, 끄면 건너뜀)
- 단위는 숫자 뒤나 대괄호 안일 때 한국어로 읽습니다: 2 A → 2 암페어, 220 V → 220 볼트, 10 μF → 10 마이크로패럿, [Wb/m²] → 웨버 매 제곱미터. 문장 속 변수 V, I 등은 글자 그대로 읽습니다.
- 외부 서버나 API 키를 쓰지 않습니다. 브라우저 내장 음성 합성(Web Speech API)만 사용합니다.
- 갤럭시탭: 크롬 권장. 한국어 음성이 없으면 설정 → 일반 → 글자 읽어주기(TTS)에서 Google 또는 삼성 엔진의 한국어 음성을 내려받으세요.
- 화면이 꺼지거나 다른 앱으로 넘어가면 읽기가 멈춥니다(재생 중에는 화면 꺼짐 방지를 요청합니다).

## S펜 필기

- 상단 **S펜 필기**를 누르면 현재 단원 또는 문제의 노트가 열립니다. 가로 화면은 오른쪽, 태블릿·휴대폰 세로 화면은 아래쪽에 표시됩니다.
- 기본값은 **S펜만 필기 + 터치 잠금**입니다. 손바닥과 손가락 입력은 필기·버튼 누르기·본문 이동을 하지 않습니다. S펜으로 버튼을 누르거나 **본문 ↑/↓**로 이동합니다. 손가락으로 이동하고 싶을 때만 **터치 이동 허용**으로 바꾸며, 이 상태에서도 손가락은 잉크를 만들지 않습니다.
- 펜 색·굵기·필압, 획 지우개, 되돌리기·다시 실행, 쪽 비우기, 여러 쪽 추가를 지원합니다. 기기가 펜 옆 버튼 또는 지우개 팁을 알려 주면 지우개로 처리합니다. PC에서는 별도로 **마우스 필기**를 켤 수 있습니다.
- 리더에서 보이는 단원이 바뀌거나 문제를 옮기면 해당 노트를 따로 불러옵니다. 필기창을 열면 페이서 읽기를 멈추고 읽기 조작판을 접습니다. 단원·문제 번호는 기존 학습 기록과 구분됩니다.
- 필기는 **이 기기·이 브라우저에 자동 저장**됩니다. 문제 풀이·즐겨찾기의 Google 동기화와 별개입니다. **전체 필기 백업 / 백업 가져오기**로 다른 기기에 옮기고, **현재 쪽 PNG**로 한 쪽을 저장할 수 있습니다.
- 큰 필기 백업은 브라우저가 지원하면 `.json.gz` 한 파일로 자동 압축합니다. 일반 JSON과 압축 백업을 모두 가져올 수 있습니다. 압축을 지원하지 않는 브라우저에서는 JSON으로 저장하며, 다른 기기의 압축 파일은 먼저 압축을 풀어 가져옵니다.
- 저장 실패 시 화면에 안내하고 저장되지 않은 내용을 메모리에 유지합니다. 백업을 내려받은 뒤 파일 저장 여부를 확인하세요. 브라우저 데이터 삭제 시 로컬 필기도 지워지므로 필요한 기록은 백업합니다.

## 문제은행 사용법

- 상단 **기출** 카테고리에서 추가된 전기 3,876문항만 모아 볼 수 있습니다. **단원별 연습**은 기존 4,950문항, **전체**는 두 종류를 모두 포함합니다. `questions.html?category=past` 주소로 기출을 바로 열 수 있습니다.
- 푼 문제는 문제 상단과 문제 번호 목록에 **풀이 완료 · 최근 정답/오답**으로 표시합니다. 전체 보기에서는 마지막 풀이 다음의 미풀이부터 이어지며, **다음 미풀이**로 풀었던 문제를 건너뜁니다. 선택한 범위는 이 브라우저에 저장되어 다시 접속할 때 복원됩니다. 오답노트·즐겨찾기에서는 풀었던 문제도 순서대로 복습할 수 있습니다.
- 과목·단원·세트를 고르고 문제를 푼 뒤 **정답 확인**을 누릅니다. 선택지별 해설을 볼 수 있습니다.
- **전기 기출·복원**을 선택하면 2023~2025년 전기 자료 3,876문항을 원문 이미지로 풉니다. 회차와 원래 문항 번호를 함께 표시하며, 채점 후 원문 해설을 볼 수 있습니다. 원문 확대 링크로 회로도와 수식을 크게 볼 수 있습니다.
- 가져온 자료의 객관식 3,859문항은 번호 선택으로 채점합니다. 주관식 17문항은 정답·해설을 확인한 뒤 직접 맞음/틀림을 기록합니다. 출처에 해설이 없는 문항에는 해설 미제공을 표시합니다.
- **풀이 유형**에서 계산필요 / 계산불필요(단순암기)를 고를 수 있습니다. 검색·오답노트·즐겨찾기에도 함께 적용됩니다.
- 수치 대입·연산·변환·식 도출이 필요한 문제는 계산필요, 정의·성질·공식 확인과 기본 개념 판단은 계산불필요로 분류했습니다. 문항별 분류는 `data/question-bank/classifications.json`에 보관합니다.
- 틀린 문제는 **오답노트**에 모입니다. 다시 풀어 맞히면 자동으로 빠집니다.
- 별 버튼으로 **즐겨찾기**를 추가하거나 해제합니다. 정답 여부와 관계없이 유지됩니다.
- 풀이 기록과 즐겨찾기는 먼저 해당 기기의 브라우저에 저장됩니다. **Google로 로그인**하면 기존 로컬 기록을 계정 기록과 자동으로 합치고, 같은 계정으로 로그인한 다른 기기에서도 이어서 풀 수 있습니다. 현재 동기화는 등록된 Google 계정에서 사용할 수 있습니다.
- 인터넷이 끊긴 동안 푼 문제와 즐겨찾기 변경은 이 기기에 보관했다가 다시 연결되면 전송합니다. 상태 표시가 **동기화 완료**인지 확인하세요. 연결 오류가 나면 **다시 동기화**를 누릅니다.
- **로그아웃**해도 현재 기기의 기록은 남습니다. **기록 백업 저장 / 백업 가져오기**도 계속 사용할 수 있습니다. 같은 문제를 여러 기기에서 풀었다면 가장 최근 기록을 사용하며, 재연결 때 풀이 횟수를 중복 합산하지 않습니다.
- 계측 단원별 연습은 NotebookLM 생성 문제이고, 전기 기출·복원은 기존 전기 문제 풀이 웹앱의 원문 자료입니다. 실제 시험문제나 정답의 정확성을 보장하지 않습니다.

## 외부 리소스

- 글꼴: Google Fonts (IBM Plex Sans KR, IBM Plex Mono)
- 수식: MathJax 3.2.2 (cdn.jsdelivr.net)
- 문제 해설의 기존 수식 표시: 로컬 KaTeX 0.19.0 CSS·폰트. 원저작권 고지는 CSS에 포함되어 있습니다.
- 문제은행 계정 연결: Firebase JavaScript SDK 13.0.0 (gstatic), Google 로그인, Cloud Firestore. 로그인한 사용자의 풀이 기록·즐겨찾기 상태를 저장하며 이메일 주소는 학습 기록에 저장하지 않습니다. 공개 앱 설정은 `firebase-config.json`, 계정 접근 제어는 Firestore 서버 규칙에서 관리합니다.

인터넷이 없으면 글은 읽히지만 수식은 TeX 원문으로 보이고 글꼴은 기기 기본 글꼴로 바뀝니다.

## 주의

- 비공식 자료입니다. 한국전력기술 및 출제기관과 관련이 없습니다.
- 출제 범위·비중을 예측하거나 보장하지 않으며, 오류가 있을 수 있습니다. 공식 수험 안내와 표준 교재를 우선하세요.
- 페이서 리딩의 예제와 설명, 단원별 연습문제, 전기 기출·복원 원문은 출처와 작성 방식이 다릅니다. 문제은행에서 각 자료의 출처를 구분해 표시합니다.
