# 계측 페이서 리딩

한국전력기술 계측 직렬 필기 대비 비공식 학습 자료입니다. 정적 웹사이트(HTML·PDF)라서 서버 없이 GitHub Pages, Netlify 같은 정적 호스팅에 그대로 올리면 됩니다.

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 페이서 리딩 앱. 노란 형광이 어절 단위로 이동하며 읽기를 이끕니다. 01~06권 130단원 내장 |
| `pdfs.html` | PDF 받기 페이지 |
| `questions.html` | 99개 단원, 198세트, 4,950문항 문제은행 |
| `data/question-bank/` | 단원별 문제·선택지·정답·해설 데이터 |
| `pdf/00_5day_plan.pdf` | 5일 학습 플랜(타임라인·하루 체크리스트·기출 대응표) |
| `pdf/01~06_*.pdf` | 과목별 필기형 PDF(갤럭시탭 16:10 가로, 오른쪽 필기 패드) |
| `404.html` | 잘못된 주소를 첫 화면으로 돌려보냄 |
| `.nojekyll` | GitHub Pages가 파일을 가공하지 않도록 하는 빈 파일 |

## 페이서 리딩 사용법

- ▶ 재생, 단어를 누르면 그 위치부터, ◀ ▶ 버튼은 문장 단위 이동
- 속도 60~600 어절/분, 묶음 1~3어절, 글자 크기, 핵심만(통암기·공식·표·함정), 읽은 곳 흐리게, 문장 끝 쉼, 전체화면
- 갤럭시탭 가로(목차 고정)·세로(목차 서랍) 모두 지원, 다크모드 자동
- 읽던 위치와 설정은 각자 브라우저에만 저장됩니다(서버 전송 없음)

## 음성 읽기(한국어 TTS)

- 하단 **음성 읽기**를 켜고 ▶를 누르면 기기에 설치된 한국어 음성이 문장 단위로 읽고, 노란 형광이 읽는 단어를 따라갑니다.
- **배속** 0.5~3배, **목소리** 선택, **수식 읽기**(수식을 "R 분의 V 제곱"처럼 한국어로 읽음, 끄면 건너뜀)
- 단위는 숫자 뒤나 대괄호 안일 때 한국어로 읽습니다: 2 A → 2 암페어, 220 V → 220 볼트, 10 μF → 10 마이크로패럿, [Wb/m²] → 웨버 매 제곱미터. 문장 속 변수 V, I 등은 글자 그대로 읽습니다.
- 외부 서버나 API 키를 쓰지 않습니다. 브라우저 내장 음성 합성(Web Speech API)만 사용합니다.
- 갤럭시탭: 크롬 권장. 한국어 음성이 없으면 설정 → 일반 → 글자 읽어주기(TTS)에서 Google 또는 삼성 엔진의 한국어 음성을 내려받으세요.
- 화면이 꺼지거나 다른 앱으로 넘어가면 읽기가 멈춥니다(재생 중에는 화면 꺼짐 방지를 요청합니다).

## 문제은행 사용법

- 과목·단원·세트를 고르고 문제를 푼 뒤 **정답 확인**을 누릅니다. 선택지별 해설을 볼 수 있습니다.
- 틀린 문제는 **오답노트**에 모입니다. 다시 풀어 맞히면 자동으로 빠집니다.
- 별 버튼으로 **즐겨찾기**를 추가하거나 해제합니다. 정답 여부와 관계없이 유지됩니다.
- 풀이 기록과 즐겨찾기는 해당 기기의 브라우저에 저장됩니다. **기록 백업 저장 / 백업 가져오기**로 다른 기기로 옮길 수 있습니다.
- NotebookLM에서 생성한 연습문제이며 실제 시험문제나 정답의 정확성을 보장하지 않습니다.
